# 生产就绪评估

这份文档诚实列出当前项目已具备和尚未具备的生产级能力，不夸大个人项目的成熟度。部署前用于核对运行条件；历史验证记录不能替代目标环境验收。

> 状态核对：2026-10-21，D10核对源码基线 `0e23f68`；后续D25基于 `e187287` 验证。表格区分仓库实现/配置与目标环境验收；本轮未查询远端 CI 或生产部署。D25 已完成有界本地服务/SQL验证，D27持续审查与B16目标环境容量仍保留，见 [问题总表](review-findings.md)，逐次验证见 [开发与验证](development.md)。

## 已实现的能力与验证入口

2026-10-22基础版收尾范围与真实服务栈浏览器联调见[收尾验收](release-acceptance.md)。已补[人工备份恢复流程](backup-recovery.md)与[仓储操作手册](warehouse-operations.md)；本地隔离演练和目标部署验收分别记录，下表未实施的自动化运维能力不因此关闭。

| 能力 | 实现位置与说明 |
| --- | --- |
| CI | `.github/workflows/ci.yml` 按改动范围执行 Go、前端与容器/E2E 门禁；纯文档跳过业务检查。配置存在不表示当前提交已在 GitHub 通过。 |
| E2E | `scripts/e2e.ps1` 提供独立 Compose + Playwright 入口；历次真实业务与只读 UI fixture 的执行范围分别记录，不能用夹具测试替代真实库存写入验收。 |
| 健康检查 | `internal/app/router.go` 的 `/healthz` 端点，Docker Compose healthcheck |
| 结构化日志 | `internal/pkg/log` 输出 JSON；请求上下文附 request_id/user_id，操作审计记录租户。并非所有日志行都自动包含这些字段，审计仍为 best effort。 |
| 指标 | HTTP/连接池、事务尝试/重试、导入队列/恢复、实例行锁及幂等清理指标和 Grafana 配置已实现；D12/D26 本地验证范围见记录，生产采集/渲染及告警未据此验收。 |
| Docker 部署 | `deploy/docker-compose.yaml`：多阶段构建、非 root 用户、持久化卷、健康检查 |
| 版本化迁移 | `cmd/migrate` + golang-migrate，迁移容器独立执行，release 不运行 AutoMigrate |
| 安全加固 | release 模式拒绝弱 JWT/默认 DSN/缺失密码；权限注册表白名单；演示重置按租户隔离 |
| 多租户隔离 | GORM 回调注入 tenant_id；平台旁路与精确租户区分；裸表查询显式过滤 |
| 并发控制 | MySQL 行锁、FIFO、条件更新和 run_token 已实现，并有历史并发回归；D25补单据规模上限和本地行锁/SQL证据，保留仓库保护锁；不据本地结果保证目标环境吞吐，见[规模验证](scale-validation.md)。 |
| 压测 | 已有分配证明及读取/出库/拣货模型；D22 范围清理默认预览，真实 k6 回环夹具已验收，未执行真实清理，也未替代目标负载的性能验收。 |

## 仓库尚未提供或目标部署尚未验收

| 能力 | 缺失原因与风险 |
| --- | --- |
| 数据库备份 | 有人工导出/隔离恢复流程；未配置定时任务、异地保管及轮转，不能保证发生数据丢失时有可用恢复点 |
| PITR | 没有 binlog 点恢复流程；误操作后无法回退到精确时间点 |
| 恢复演练 | 本地隔离演练结果见收尾验收；目标服务器、实际上传文件及恢复后实物账目核对仍须现场验收 |
| RPO/RTO | 未定义恢复目标和恢复时间目标 |
| 自动回滚 | 没有蓝绿发布或自动回滚机制；部署失败需手动回退 |
| 多实例 Worker | 导入消费者使用数据库队列竞争，但未验证跨实例文件存储共享和 fencing |
| 分布式限流 | 登录限流仍为进程内；AI 分钟/日额度已在共享 Redis 原子计数，同一 Redis 下可共享，Redis 故障时仍按既有策略放行，不能宣传为故障下严格额度 |
| 统一配置中心 | 配置来自 config.yaml + 环境变量；没有动态配置更新 |
| 证书自动续期 | Caddy profile 支持 Let's Encrypt，但未验证长期运行续期 |
| 滚动升级 | Compose 重启会短暂中断；没有零停机部署策略 |
