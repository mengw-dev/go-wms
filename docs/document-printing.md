# 单据打印与条码标签

开发分支 `feature/document-printing` 基于库存预警本地提交 `e5cf56d`，这是当时开发范围；现main同时包含波次工作台，工作台提供独立拣货单打印。浏览器打印，无新增后端接口、中间件、打印代理或业务状态；库存预警说明见[库存预警](inventory-alerts.md)。

## 入口与权限

| 入口 | 输出 | 权限 |
| --- | --- | --- |
| 入库单详情 → 打印预览 | 入库明细、批次、应收/已收/不良数量、签字栏 | `wms:inbound:view` |
| 出库单详情 → 打印预览 | 出库明细、原分配库位/批次/数量、已拣数量、签字栏 | `wms:outbound:view` |
| 盘点单详情 → 打印预览 | 已保存账面/实盘/差异、空白填写栏、签字栏 | `wms:stocktake:view` |
| 货品管理 → 单行“标签”或所选/本页标签预览 | 货品名称、编码、单位、原条码值 | `wms:basic` |
| 库位管理 → 单行“标签”或所选/本页标签预览 | 原库位编码、仓库上下文 | `wms:basic` |

前端单据预览路由为 `/print/inbound/:id`、`/print/outbound/:id`、`/print/stocktake/:id`，直接复用已有受权限、租户保护的详情 GET 接口。仓库名称只在有基础资料权限时查询；失败或无权限显示单据仓库 ID，不阻止只读用户查看和打印。标签资料沿用基础资料列表权限，没有新建万能打印接口。

## 单据语义

- 进入预览重新查询已保存详情，刷新失败即清除旧纸面并禁用打印；不打印未保存的盘点输入。
- 盘点未录入显示空栏，已经录入零必须显示0；草稿差异按已保存实盘减快照账面，非草稿使用后端保存的差异。
- 出库当前作业只列 `ALLOCATED` 分配，保留每条原库位、批次和数量，不跨库位合并，不重新分配。其他状态独立列入“分配历史”，标明状态且不能作为拣货指令；没有当前分配时明确提示不能执行拣货。异常重新分配的取消记录继续保留供追溯。
- 不把不同货品的数量混成总件数。数量使用各货品库存计量单位。
- 纸面包含当前状态、快照时间与签字栏；业务可能在预览后变化，现场必须核对，必要时刷新。
- 打印、取消打印、保存PDF、重印均不收货、不上架、不拣货、不审核、不扣减库存，也不写“已打印”状态。浏览器事件不能证明纸张已成功打印。
- 单据为A4，打印时解除屏幕局部滚动与固定高度，长表可跨页并重复列头；手机在预览内容内横向/纵向滚动，操作栏可见。主题仅影响屏幕外壳，纸面统一白底黑字。

## 条码与标签规格

使用固定依赖 `jsbarcode@3.12.3` 的Code128编码，Vue绘制SVG，不拼接用户HTML、不上传条码内容到外部服务。

- 货品使用原 `sku.barcode`；库位使用原 `location.code`。字符串原样保留，包括前导零，不转为数字，不加扫码协议前缀。
- 收货/上架/拣货已接入分字段的键盘型扫码与手动核对，见[扫码辅助作业](scan-assistance.md)；操作人员仍须在相应字段扫描，不提供通用混合扫码分流或手机相机识别。
- 单张90×45mm，A4两列、每页五行10张，四毫米间隔；每条记录1–20份，单次总计最多200张。按页分组防止一个标签被拆到两页。
- 每模块固定0.3mm，左右各十模块静区，黑条白底；不缩窄长条码来勉强适配。
- 仅支持1–64位可打印ASCII，且实际编码宽度（含静区）不超过80mm。中文、控制字符、空白、过长编码会提示原因并禁用整批打印，不静默漏印。64位是输入上限，不表示所有64位值都能放入当前规格。
- 库位标签含仓库上下文，但编码本身保持原值。货品名/辅助说明过长时可省略显示，原条码值完整保留。
- “本页”指当前已加载页面；表格选中后打印所选记录，不自动拉取全库。标签使用列表快照，资料修改后须刷新列表再重印。
- 重新登录、退出或会话ID变化关闭并清除标签预览；同一演示会话正常续期只更新有效期，预览继续保留。等待字体时关闭、切换批次或离开页面，旧打印请求失效。

## 打印与现场验收

选择“打印 / 保存 PDF”调用浏览器打印对话框。请选择A4、100%实际大小，关闭浏览器附加页眉页脚并核对预览；此标签样板对应上述纸张尺寸和间隔，不保证匹配所有现成不干胶纸。热敏单张标签、物流电子面单、模板编辑器、静默打印、打印队列和打印审计均不在本版范围。

本地Chromium验证通过只读请求、完整行、日夜主题及手机局部滚动，并导出长出库单、盘点单、20张标签检查分页和内容完整性；这是浏览器/PDF验证，不替代目标浏览器、打印驱动、纸张偏移和扫码枪的实机验收。采用Code128表达原值，不宣称EAN/GS1条码认证。

技术依据：[MDN浏览器打印](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Media_queries/Printing)、[JsBarcode官方仓库与对象编码接口](https://github.com/lindell/JsBarcode)。
