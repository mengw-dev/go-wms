# 前端 UI 优化记录（2026-10-08）

本轮处理公共工作台布局及仪表盘、入库单、出库单、库存查询。保留 Vue 3、Element Plus、Pinia、现有 API 和业务操作流程。

## 问题与实现

| 原问题 | 修改 |
| --- | --- |
| 固定 220px 侧栏压缩窄屏业务区 | 桌面侧栏可收起；900px 及以下改用导航抽屉；菜单共用权限逻辑，支持 Escape、关闭后恢复焦点、路由切换关闭 |
| 筛选项宽度零散、工具栏层级弱 | 入出库筛选区改为四列/手机两列网格；结果总数与导入靠左、批量操作靠右；无选择时禁用批量入口 |
| “数量”列语义不清 | 入库明确为“已收 / 应收”，出库明确为“已拣 / 应出”，保留不良量/分配量辅助信息 |
| 手机固定操作列遮挡业务字段 | 入出库操作列在窄屏随表格横向滚动，并提示滑动；分页换行；新建明细、日期范围面板及库存流水抽屉适配窄屏 |
| 深色输入控件黑底、部分状态文字偏淡 | 补齐填充色、主按钮文字、状态文字和指标颜色令牌；保留浅色靛紫、深色翡翠绿；抽查主按钮正常/悬停及警告状态文字对比度不低于 4.5:1 |
| 仪表盘硬编码指标颜色，键盘操作不完整 | 指标颜色跟随主题；补齐统计卡/快捷入口/最近单据键盘操作；欢迎区、统计网格与单据行分层；按权限隐藏无权查看的单据卡 |
| “异常单”实际只是取消状态统计 | 改为“今日取消入库单/出库单”，说明统计按单据创建时间计算 |
| 库存页缺少页面说明 | 增加标题及现存量、可用量、分配量的关系说明 |

- `docs/code-index.md`：同步布局与公共样式导航。

## 边界

- 浏览器检查拦截所有 API，只使用模拟数据；没有运行连接真实后端的全量业务 E2E，也没有写入业务数据库。
- 本轮未修改后端，因此没有重复 Go 检查。没有改动库存一致性、单据状态机、API 契约或 Demo 事件依赖方向。
- 公共样式覆盖其他业务页，但未逐一验收所有页面、所有弹层、所有设备及浏览器；对比度断言也不是全站无障碍认证。
- 本次提交仅包含 UI 优化、配套测试与文档；原有未跟踪文件 `scripts/k6/cleanup-allocation.js` 不包含在内。

## 业务页面统一布局（2026-10-20）

本轮已完成业务列表、单据详情、作业弹窗与 AI 页面布局统一。仪表盘、演示页面和登录页保持原有布局；不修改后端 API、权限判断、业务状态机、幂等恢复和 Guide 事件契约。

### 设计依据与实现

参考 [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)的标题/操作一致性与导航弱化、[Shopify 索引表格](https://shopify.dev/docs/api/app-home/latest/patterns/compositions/index-table)的集中搜索筛选，以及 [Carbon 操作层级](https://www.carbondesignsystem.com/building-blocks/core/patterns/common-actions/tab-1)。保留浅色靛紫、深色翡翠绿，不引入新的 UI 框架。

- 列表：统一标题、说明与右上新增入口；筛选区压缩为常用控件，查询为次级操作，结果总数、表头、行操作与分页使用一致的间距。较长结果在表格内滚动，表头保留。入库批次筛选可展开，收起后显示已启用条件数量，重置仍清除全部条件。
- 覆盖入库、出库、盘点、任务、库存明细/SKU 汇总、仓库、库位、货品、用户、角色、操作日志。
- 详情：入库/出库/盘点单号、状态和动作集中展示，基础信息用可换行资料网格；保留原有明细、分配、关联任务、盘点录入和差异汇总。
- 弹层：保留新增/编辑、导入、角色分组权限等原有功能；收货/上架/拣货补充真实单号与操作提示，内容可独立滚动，确认/取消留在底部。待确认操作恢复、租约领取、扫码核对均保留。
- AI：统一页面标题与输入区，建议问题按宽度换列，聊天区域独立滚动；回答仍按纯文本渲染。
- 隔离：通过 `Layout.vue` 的 `layout--business` 标记与显式 `business-dialog` 类启用新样式，不改动全局主题令牌、仪表盘或演示页面源文件。业务布局保留手动引导状态条的顶部预留空间，防止紧凑样式覆盖原有间距、遮挡新建按钮；双主题增加真实 Guide 状态下关闭记录窗后仍能点击新建的回归。
