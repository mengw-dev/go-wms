## 2026-10-21 手机业务页面适配（本地）

覆盖入库/出库/盘点列表与详情、库存明细/汇总/流水、任务、仓库/库位/货品、用户/角色/操作日志，以及新增和收货/上架/拣货弹窗。仪表盘与演示首页维持既有设计；公共演示悬浮条仅在手机浮动模式下收紧。

- 768px 及以下将原表格行显示为带字段名称的纵向记录卡片，复用原有单元格、状态、权限、选择和操作处理，不维护两套业务列表。全部字段及操作保留，长单号/批次可折行；列表和详情明细在各自内容区滚动。选择本页、逐条选择与批量操作继续可用。
- 搜索筛选可展开/收起，常用条件两列，日期与操作占整行，筛选过长时内部滚动。折叠仅改变展示，不重置查询条件。桌面始终展开。
- 手机分页固定分成“总数/每页条数”和“上一页/页码/下一页”两行，页码密度随宽度调整，避免下一页按钮单独落行；仍转发原有分页和每页条数事件。
- 手机标题和主操作并排，表单标签在输入框上方；弹窗限制在动态视口内，内容滚动，确认/取消留在底部。日夜配色继续引用现有主题变量。
- 演示悬浮条缩为状态与控制入口，保留拖拽；重复的重置入口与完整隔离说明在控制抽屉中仍可访问。默认底部预留空间与紧凑条匹配，不遮分页；演示首页底栏不受影响。

组件实现沿用 Element Plus 官方 [表格 cell-style 接口](https://element-plus.org/en-US/component/table.html#table-api) 和 [分页布局接口](https://element-plus.org/en-US/component/pagination.html#api)。验证结果见 [本地开发记录](development.md)。本轮按最新要求只保存本地提交，未推送或上线。

## 2026-10-20 局部滚动、演示控制条与运营仪表盘

本轮按用户要求先修复遮挡和滚动，再统一实现仪表盘；保留白天靛紫、夜间翡翠绿/深蓝两套主题。

- 演示悬浮条增加独立拖拽手柄、方向键移动、位置持久化、窗口缩小后的边界修正及恢复默认位置；仅手柄响应拖拽，重置和控制按钮仍直接点击。业务工作区预留底部空间，默认位置不遮挡分页；演示首页继续使用原底栏。
- 库存“只看有货”筛选按内容宽度排列，查询按钮紧随其后。桌面列表按实际剩余高度布局，表格内部滚动，标题、筛选和分页留在外面；详情固定单号和操作区，资料/明细在本页内容区滚动。证据列表、工程卡片及操作弹窗采用对应局部滚动，窄屏保留必要的页面滚动。
- 自动结果/分步执行弹窗高度限制在视口内。执行记录、阶段明细、右侧结果分别局部滚动，关闭、下一步、暂停/继续、真实页面与操作记录入口均保留；结果弹窗增加可访问标题。
- 仪表盘改为运营总览：四类指标、当前作业状态、按创建时间排序的最早未完成任务、近七日新建单趋势、库存/库位概况、待完成盘点和最近新建单据。保留取消单和进行中任务的筛选入口及六类业务快捷入口，长列表在卡片内滚动。
- 新增权限过滤的只读汇总 API，使用完整数据聚合而非当前分页；仓库、日期和状态可点击进入对应明细。目标列表初始化这些路由筛选，任务查询增加只读仓库过滤。刷新失败保留最后成功数据并提示更新时间；切换仓库清除旧范围数据，过时响应不覆盖新范围。

## 问题与实现

| 原问题 | 修改 |
| --- | --- |
| 固定 220px 侧栏压缩窄屏业务区 | 桌面侧栏可收起；900px 及以下改用导航抽屉；菜单共用权限逻辑，支持 Escape、关闭后恢复焦点、路由切换关闭 |
| 筛选项宽度零散、工具栏层级弱 | 入出库筛选区改为四列/手机两列网格；结果总数与导入靠左、批量操作靠右；无选择时禁用批量入口 |
| “数量”列语义不清 | 入库明确为“已收 / 应收”，出库明确为“已拣 / 应出”，保留不良量/分配量辅助信息 |
| 手机固定操作列遮挡业务字段 | 入出库操作列在窄屏随表格横向滚动，并提示滑动；分页换行；新建明细、日期范围面板及库存流水抽屉适配窄屏 |
| 深色输入控件黑底、部分状态文字偏淡 | 补齐填充色、主按钮文字、状态文字和指标颜色令牌；保留浅色靛紫、深色翡翠绿；抽查主按钮正常/悬停及警告状态文字对比度不低于 4.5:1 |
| 仪表盘硬编码指标颜色，键盘操作不完整 | 指标颜色跟随主题；补齐统计卡/快捷入口/最近单据键盘操作；欢迎区、统计网格与单据行分层；按权限隐藏无权查看的单据卡 |
| “异常单”实际只是取消状态统计 | 改为“今日取消入库单/出库单”，说明统计按单据创建时间计算 |
| 库存页缺少页面说明 | 增加标题及现存量、可用量、分配量的关系说明 |

### 设计依据与实现

参考 [Linear 2026 界面更新](https://linear.app/now/behind-the-latest-design-refresh)的标题/操作一致性与导航弱化、[Shopify 索引表格](https://shopify.dev/docs/api/app-home/latest/patterns/compositions/index-table)的集中搜索筛选，以及 [Carbon 操作层级](https://www.carbondesignsystem.com/building-blocks/core/patterns/common-actions/tab-1)。保留浅色靛紫、深色翡翠绿，不引入新的 UI 框架。

- 列表：统一标题、说明与右上新增入口；筛选区压缩为常用控件，查询为次级操作，结果总数、表头、行操作与分页使用一致的间距。较长结果在表格内滚动，表头保留。入库批次筛选可展开，收起后显示已启用条件数量，重置仍清除全部条件。
- 覆盖入库、出库、盘点、任务、库存明细/SKU 汇总、仓库、库位、货品、用户、角色、操作日志。
- 详情：入库/出库/盘点单号、状态和动作集中展示，基础信息用可换行资料网格；保留原有明细、分配、关联任务、盘点录入和差异汇总。
- 弹层：保留新增/编辑、导入、角色分组权限等原有功能；收货/上架/拣货补充真实单号与操作提示，内容可独立滚动，确认/取消留在底部。待确认操作恢复、租约领取、扫码核对均保留。
- AI：统一页面标题与输入区，建议问题按宽度换列，聊天区域独立滚动；回答仍按纯文本渲染。
- 隔离：通过 `Layout.vue` 的 `layout--business` 标记与显式 `business-dialog` 类启用新样式，不改动全局主题令牌、仪表盘或演示页面源文件。业务布局保留手动引导状态条的顶部预留空间，防止紧凑样式覆盖原有间距、遮挡新建按钮；双主题增加真实 Guide 状态下关闭记录窗后仍能点击新建的回归。
