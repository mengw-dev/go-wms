# 演示模式（多演示账号）

演示模式用于把项目临时开放给体验者、面试官或朋友体验。它基于多租户隔离实现：每个演示账号（demo1~demoN）独占一个租户，**数据完全隔离、互不影响**；退出或超时后该账号数据自动重置，不影响其他演示账号。

实现边界：业务场景变更调用真实 inbound、outbound、stocktake Service，不维护第二套状态机；操作记录、运行状态与指标快照、数据重置和部分统计使用演示环境专用读写路径，可能直接查询或重置相关数据表。

## 功能

- 多演示账号：默认 5 个（`demo1` ~ `demo5`），密码均为 `demo123456`，各占独立租户（固定号段 10001+）
- 自动分配：登录页“在线体验”按钮领取一个空闲演示账号并自动登录；全部占用时提示稍后再试
- 单账号单会话：同一演示账号同一时间只允许一个有效会话（会话锁按租户隔离）
- 空闲超时：只有用户有操作时才向后端续期，默认挂机 5 分钟自动释放会话并恢复初始数据
- 进入即重置：每次领取会话都会恢复该账号的初始演示数据（清掉上一手访客的改动）
- 退出即重置：主动退出或会话空闲到期后恢复初始数据；刷新页面复用有效会话
- 首页自动/分步流程：入库、收货、上架、核对库存流水、出库 FIFO 分配、拣货发货；后端 `/demo/run/full` 另含盘点与库存调整
- 模拟 Excel 批量入库：体验者可选择张数和每张数量，只创建草稿，后续自己批量提交、审核、收货、上架
- 模拟上游批量出库：体验者可选择张数和每张数量，只创建草稿，后续自己批量提交、审核、拣货
- 批量创建盘点单：只创建盘点草稿，体验者自己录入实盘数量并审核
- 并发出库分配实验：体验者可选择并发张数和每张数量，页面展示实验重点、总需求量、成功/业务拒绝数量和最终库存
- 运行状态与指标快照：展示 MySQL、Redis、连接池、Go 协程、内存和业务数量，不用于压力测试或容量评估
- 操作记录：展示接口操作、业务单据、任务和库存流水
- 手动重置：演示控制台中的“重置数据”（只影响当前演示账号）

## 初始数据与分步恢复

初始种子只提供 1 个仓库、4 个库位、5 个 SKU 和 4 条期初库存（合计 230），不直接插入已完成入库单或已发货出库单。期初流水类型为 `OPENING`，来源编号为 `SEED-*`，操作人为 `system-seed`。真实单据、明细、任务、分配和收发流水由业务接口生成；旧版 `system-seed` 单据在列表与详情标注“历史演示样本”，不会因启动而自动删除或改账。

分步演示先把进度和操作意图一起保存到当前标签页的 `sessionStorage`，按账号与演示会话隔离。刷新后从“演示控制 → 继续分步演示”打开，保持暂停，由用户继续执行。收货、上架和拣货恢复时携带原 `Idempotency-Key` 和原参数，即使任务已完成也能回放。建单、提交、审核或建库位丢失响应后先只读核对，无法唯一确认时保留待确认状态，不自动另发写请求；可到真实页面确认并完成该步骤，再恢复核对，或明确重置演示。

自动演示可暂停；关闭弹窗、跳转业务页、组件销毁或账号/会话切换会停止后续请求并取消客户端等待。暂停不回滚已经提交的业务操作。未完成的演示不能被新运行覆盖；只有服务端重置成功后才清理当前检查点。存储损坏、无法写入或运行开始已超过 7 天会阻止继续写入，需要核对或重置。恢复仍要求原演示会话有效；清除浏览器存储、换设备或跨标签页原子互斥不在保证范围内。

## 配置

环境变量：

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `WMS_DEMO_ENABLED` | `false` | 演示模式总开关；`false` 时后端不挂载任何 `/demo` 路由、演示账号被禁用、登录页隐藏演示入口（生产部署保持关闭，本地一键启动脚本通过 `.env` 设为 `true`） |
| `WMS_DEMO_INSTANCES` | `5` | 演示账号数量（1~99），账号名为 `demo1`~`demoN`，各占独立租户 |
| `WMS_DEMO_PASSWORD` | `demo123456` | 演示密码（所有演示账号共用） |
| `WMS_DEMO_SESSION_TTL_SECONDS` | `300` | 演示会话空闲超时时间 |

调整演示账号数量（如从 5 个增加到 8 个）：修改 `WMS_DEMO_INSTANCES=8` 后重启服务即可。启动时会自动创建新增账号（demo6~demo8 及其租户、角色），多余的旧账号（如从 8 收缩回 5 时的 demo6~demo8）会被自动禁用。

演示模式必须连接 Redis。Redis 中的会话键（按租户隔离）：

- `gowms:demo:active:{tenantID}`：该演示账号当前有效会话（每个演示账号一把锁）
- `gowms:demo:reset-lock`：数据重置的跨实例互斥锁

## 本地使用

Windows：

```powershell
.\scripts\windows\start.ps1
```

启动完成后访问 `http://127.0.0.1`：

- 访客：点击登录页“在线体验（自动分配演示账号）”，系统自动分配空闲账号并登录
- 也可以手动输入 `demo1`、`demo2`…（密码 `demo123456`）指定账号登录

登录后进入演示首页，右下角“演示控制”可查看进度、恢复或重置。

初始化或修复演示账号（仅开发/演示环境；release 部署由应用启动时按配置同步）：

```powershell
go run ./cmd/migrate seed-demo
```

## 体验者/面试官使用说明

可以把下面这段直接发给对方：

> 演示地址：http://你的服务器IP  
> 打开登录页后点击“在线体验”按钮即可，无需输入账号密码（系统会自动分配一个独立演示账号）。  
>
> 登录后在首页点击“开始自动演示”，选择自动完成或分步执行，也可以先批量创建草稿，再由自己处理。刷新后可从右下角“演示控制”继续原流程。需要恢复初始数据时点击“一键重置数据”或“退出并重置”。多人可以同时体验（每人一个独立账号，数据互不影响）；如果提示演示席位已满，请稍后再试。

## 压测和 Grafana 展示

正常业务流程、k6 并发压测和 Grafana 指标查看见 [load-testing.md](load-testing.md)。压测建议使用独立的管理员账号在专用环境执行，避免压测数据影响演示账号的体验数据。

## 安全边界

演示账号拥有 `wms:demo` 以及演示所需业务权限，但没有系统用户、角色和操作日志管理权限。生产环境仍必须：

- 使用 HTTPS
- 修改默认管理员密码
- 把密码和 JWT 密钥放到环境变量或密钥管理系统中
- 只开放 `80/443` 和受限的 SSH 端口
- 不要开放 MySQL、Redis、API 管理端口和 Prometheus
- 不要把真实业务数据放进演示环境（演示租户号段 10001+ 与业务租户隔离，但演示环境本身不设防）
