# C09 / I12：演示操作确认的会话归属

2026-11-03，基线c17a8af。I12仍包含待确认业务记录放弃路径，本项只完成演示重置/退出及共享确认器，不代表C09或I12全组完成。

## 根因与修改

DemoConsole原先在用户确认重置之后才读取身份，旧确认可对后来建立的会话发起重置；请求返回只比较用户ID/租约也不能识别相同标识重新登录。退出确认同样没有覆盖确认等待期。

- 重置在确认之前捕获完整认证代次，确认后和响应后均核对，卸载后不发请求、不清演示进度、不广播新会话的数据变化。重置进行中禁止重复启动。退出复用页面与会话作用域确认。
- `useScopedConfirm`支持可选业务目标，目标/路由/登录变化立即关闭本次确认。每次确认有独立标识，旧Promise的finally不会取消新确认的占用，目标A→B→A也不接受旧确认。共享登录变化即使storage事件未到达也拒绝完成。
- 不修改服务端重置/租约语义，不取消已经送达服务器的重置；后者属于C08在途操作与接管约束。
