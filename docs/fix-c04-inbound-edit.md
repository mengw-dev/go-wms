# C04 第二部分：入库草稿编辑冲突

对应 I5 的入库草稿实例。基线035ff7f，2026-11-03实施。C04中D4/I34已单独完成；用户管理旧表单覆盖仍待修，不能将整个I5或C04记为完成。

## 根因与实现

旧代码保存时锁读当前 version，再拿这个新版本做更新条件。两个编辑者都打开数量2，A改成5保存后，B只改备注却携带旧数量2，仍可保存并覆盖A。数据库更新原子并不等于保护编辑窗口。

入库单响应现在提供 version；编辑请求单独使用 UpdateOrderReq，要求正整数 expected_version。Service在原单头锁内比较客户端版本，不一致返回HTTP409 / 40902，尚未执行资料引用或主单/明细改写。复用现有版本列和事务，无数据库迁移，无新增锁，创建、收货、上架和幂等不变。

前端从本次详情读取版本，不能借用列表旧版本或缺省猜测。冲突时保留表单、显示核对提示并禁止原样重复保存，不自动获取新版本覆盖。重新打开后才加载最新数据及版本。40902不在数据库事务自动重试集合。
