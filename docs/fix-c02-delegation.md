# C02：用户与角色管理的委派边界

原问题 D1、D2；按 DEC02 实施。基线 76da270，日期 2026-11-02。代码与后端/前端单测验收完成，浏览器验收受本地工具策略限制，待补；不将这一边界记成通过。

## 根因与规则

原接口只检查“能否进入用户管理”，没有检查“能授予什么权限”，因此普通用户管理者可以授予 admin 角色。只封堵角色分配仍不够：重置更高权限用户的密码也可以接管账号。用户页面还调用要求角色管理权限的角色列表，导致合法的用户管理者无法选角色。

现在管理写入显式携带已认证操作者 ID，在同一短事务内核对当前账号状态、管理权限和委派上限。普通管理者只能维护权限不超过自身的用户/角色；角色必须属于目标用户租户。只有租户 0 当前具有通配权限的管理员可跨租户管理系统账号；更新普通租户角色仍禁止设置平台/演示权限。内置 admin 账号及角色保持保护，普通同权限管理者之间允许委派。
