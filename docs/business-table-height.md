# 业务列表高度调整

主要业务列表默认沿用按视口自动分配高度、结果内部滚动的布局。用户可选择更高的结果区，页面随之允许上下滚动；筛选和分页始终在结果区域外。只控制呈现，不修改查询、页容量、权限、选择、业务动作或数据。

## 范围

入库单、出库单、盘点单、任务中心、库存预警、库存明细与 SKU 汇总、仓库、库位、货品、用户、角色、操作日志：12 个页面、13 个结果区域。库存两个页签独立设置。详情、操作弹窗、打印、仪表盘和演示页面保留既有尺寸与滚动策略，避免更改固定确认区或打印纸张尺寸。

## 交互

- 拖动表格底部手柄向下增加、向上减少高度；指针接近工作区上下边缘时，工作区可滚动以便继续拖动。
- “加高”增加 160px；“一屏高度”把结果区域设为接近当前视口高度，此时标题和筛选可能需要页面滚动；这与默认的“整个工作区一屏展示”不同。
- “恢复默认”或双击手柄清除当前区域的偏好，恢复自动布局。键盘聚焦手柄后，上下方向键调整 40px，Shift＋方向键 120px；Home 恢复默认，End 设为一屏高度。Esc 或指针取消恢复本次拖动开始前的尺寸。
- 自定义高度最小 160px，最大为当前视口两倍且不超过 2400px，避免误操作无限拉长。已加载的本页记录仍在结果区滚动；放大区域不会自动请求更多行，需要更多记录时继续使用原页容量与分页。
- 手机提供同一套点按控制，也可使用手柄；只在手柄上禁用默认触摸滚动，数据区域和页面保留正常滚动。

## 偏好与生命周期

使用本机浏览器 localStorage，键为 `gowms:table-height:v1:<固定区域名>:wide|compact`。按区域及是否 768px 以下分开保存，不含单据、查询条件、用户凭证或业务数据；不会同步到其他设备。损坏值回到自动布局，存储禁用时本次调整仍可使用。只有用户完成拖动或点按/键盘调整才保存。

窗口临时变小会限制显示高度，恢复大窗口后重新读取原偏好；不将临时限制覆盖保存。页签隐藏、组件销毁、指针取消时清理拖动和动画帧，解除拖动光标与文本选择限制。用户自定义高度时才允许业务主区纵向滚动，恢复默认即回到既有一屏布局；隐藏的库存页签不触发外层滚动。

组件只包裹原 `el-table`，保留其列、ref、加载、选择与操作事件；分页仍为兄弟元素。高度调整同时解除该结果区旧的 Element Plus max-height 内部限制，避免出现外框变高而数据仍被截短的空白。

实现入口：`web/src/components/common/ResizableTableArea.vue`、`web/src/utils/tableHeight.ts` 与 `web/src/business-layout.css`。验证入口：`tableHeight.spec.ts` 和 E2E `business-layout.spec.ts`；本次实际验收见 [开发记录](development.md)。
