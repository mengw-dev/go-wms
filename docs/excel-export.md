# Excel 导出

本期完成轻量版直接导出（F02.1），复用现有Excelize库，不新增中间件、数据库表、磁盘文件或后台任务平台。开发分支 `feature/excel-export` 基于已推送的打印分支55a71f8，不包含未合并的波次/拣货工作台。

## 使用入口

- 库存查询 → 库存明细 → 导出Excel：按仓库、货品关键字、只看有货等当前条件导出。
- 库存查询 → 某行“流水” → 导出Excel：保留该库存行、单据号及流水类型条件。
- 盘点单列表 → 导出盘点差异：按仓库、状态、单号筛选，汇出有差异的明细。
- 盘点单详情 → 导出盘点明细：导出本单全部已保存明细，包括未盘行。

按**点击时筛选条件**导出全部匹配记录，不受列表当前页/每页条数限制。每次最多10000条数据行，超限整次拒绝，提示缩小条件，不生成截断文件。空结果正常生成只有表头的“数据”页，“说明”页记录0条。

## API 与权限

| GET路径（前缀/api/v1） | 权限 | 筛选参数 |
| --- | --- | --- |
| `/inventory/export` | `wms:inventory` | warehouse_id、location_id、sku_id（非负ID）、sku_keyword（最多128字符）、in_stock_only（含显式false） |
| `/inventory/trans/export` | `wms:inventory` | inventory_id、order_no（包含匹配，最多64字符）、trans_type（OPENING/RECEIVE/ALLOCATE/SHIP/RELEASE/ADJUST） |
| `/stocktake/orders/export` | `wms:stocktake:view` | warehouse_id、order_id、status（DRAFT/COMPLETED/CANCELLED）、keyword（单号包含，最多64字符）、differences_only（默认false） |

前端移除page/page_size，服务端不以分页参数截断导出。非法ID、布尔值、状态和类型返回JSON错误。成功响应为XLSX附件，`Cache-Control: private, no-store`，失败走原HTTP/JSON业务错误，不用200假装成功；前端同时拒绝把200 JSON错误保存为.xlsx，并保留401登录失效处理。

每个查询明确限定当前身份的精确租户，包括tenant_id=0；客户端不能通过参数指定其他租户。原始SQL的关联条件同时限定租户和软删，库存关联资料采用LEFT JOIN，资料不可见不丢弃原库存/流水记录。没有新增导出特权，也不要求额外授予基础资料修改权限。权限在服务端路由校验。

## 对账口径

- 库存包含库存/仓库/库位/货品ID、可见名称与编码、条码、单位、批次和三数量。基础资料缺失时辅助字段留空，主记录和原ID仍在；停用资料不隐藏。
- 流水保留原变化量、现存量与可用量前后值、单据、任务、操作员、发生时间。辅助名称来自当前关联资料，不宣称是发生时的名称快照。
- 盘点编码/名称/库位/批次取自盘点快照。未录入实盘留空，已录入0为数值0；未保存输入不参与导出。
- “实盘较快照差异”=已保存实盘数-创建时快照账面；“审核调整量”使用已完成单据保存的diff_qty，针对审核时库存，两者可不同。未审核/取消单据的审核调整量留空，不将其当作已调账。
- “仅差异行”包括实盘与快照不等，或已完成单据审核调整量非零；未盘不推断为差异。若两者都为零则不列入。
- 不把不同货品数量混合汇总，不生成补货、审批或库存变动。

## 文件与运行边界

- 每份含“数据”和“说明”两页，说明记录筛选值、行数、生成口径及时间；日期统一UTC+08:00。
- ID、编码、条码及所有用户文本写为字符串单元格，保留前导零和长ID，不解释为公式。数量为数值单元格。超长单元格明确失败，不静默截断；冻结表头并提供自动筛选。
- 单次有界SELECT读取最多10001行以识别超限；不循环抓取前端分页，不持有跨文件编码的数据库事务。没有固定历史时间点导出承诺。
- 每个进程最多同时执行2个导出，繁忙返回429，无排队。查询和编码共用10秒预算，编码期间及输出前检查取消/截止；压缩步骤不能在任意CPU指令立即打断，但数据量有界。浏览器下载请求15秒。
- 离页或切换登录身份会中止在途请求，不保存旧文件；Blob URL在下载开始后回收，离页清理。浏览器“开始下载”不等于文件已成功保存到磁盘。
- 本期不做异步导出、下载中心、定时导出、长期文件保存和跨实例作业恢复（F02.2）。确认真实规模超出当前上限后再实施；没有因首版实现就声称整个异步阶段完成。
