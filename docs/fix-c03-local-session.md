## 根因与实现

登录页三个入口各自维护loading，验证表单期间也没有互斥；旧失败无条件清空认证，旧成功离页后仍写入。Layout资料刷新不校验会话，退出确认、体验释放及改密成功同样可能在换账号后清理新身份。体验会话初始化/续期/释放还可能在组件销毁后继续写入或重建定时器。

- auth store提供包含代次、token、用户ID和体验租约的身份快照。资料写入必须属于原快照且返回用户ID一致；相同token重新登录和A→B→A也不能接受旧回复。有效资料刷新仍更新昵称/权限，请求拦截器复用同一归属规则。
- 登录三个入口共用一次尝试，开始表单验证即禁止其他入口；每次异步返回后核对身份及组件生命周期。失败/卸载只能清理本次已经安装且尚未完成的临时登录。完成登录后正常页面卸载保留会话。
- Layout的退出确认、释放与改密绑定发起身份；改密弹窗也绑定打开时身份，切换后关闭并清空密码，避免旧表单以新账号提交。
- 体验初始化、心跳、空闲释放、主动释放逐请求捕获身份；替换/卸载后不能写回或重新开定时器。身份变化停止旧计时器。没有改动服务端租约或重置策略。
